## 산출물 2: 학생 JSON
`D:\VideoWorks\projects\skimcamp-shorts\students\<slug>.json` 에 아래 형식으로 저장(UTF-8).

```json
{
  "slug": "<slug>",
  "name": "<한글 이름>",
  "suffix": "학생",
  "camp": "망남한뼘해변 스킴캠프",
  "date": "2026.09.05-06",
  "subtitle": "<이 학생에 맞는 한 줄 부제>",
  "endBadge": "수료를 축하합니다",
  "endTitle": "<끝 카드 큰 글씨 (예: 해냈다!)>",
  "hero":  { "src": "assets/media/<slug>/hero.jpg", "focus": "45% 35%" },
  "cert":  { "src": "assets/media/<slug>/cert.jpg", "focus": "40% 40%" },
  "shots": [
    { "src": "assets/media/<slug>/s01.jpg", "type": "img", "focus": "45% 40%", "note": "모래 위 첫 스탠스" },
    { "src": "assets/media/<slug>/v01.mp4", "type": "vid", "focus": "50% 45%", "mediaStart": 3.5, "note": "물가 라이딩" }
  ],
  "messages": ["...", "...", "...", "...", "..."]
}
```

### 규칙
- `shots`: **8~11개** (확정 소재가 부족하면 6개까지 허용, 절대 억지로 채우지 말 것). 스토리 순서대로.
- `type`: 사진 `"img"`, 동영상 `"vid"`. 동영상은 **최대 3개**, `mediaStart`(초)로 좋은 순간을 지정. 각 shot은 약 2.3~2.8초 재생된다.
- `focus`: `object-position` 값. 원본이 가로 사진이면 9:16으로 좌우가 크게 잘리므로 **담당 학생이 화면에 남도록** 가로%를 조정한다(학생이 프레임 왼쪽이면 `"30% 40%"`, 오른쪽이면 `"70% 40%"`). 인물 얼굴이 위쪽이면 세로%를 35~40%로.
- `hero`: 학생이 가장 잘 나온 컷(얼굴 보이고 밝고 선명). 마땅한 것이 없으면 수료식 사진 중 다른 컷을 쓴다.
- `cert`: 담당 학생의 수료증 수여 사진.
- `messages`: 격려·칭찬 한국어 **5개**. 실제 화면에 보이는 내용과 맞아야 한다. 어린이·학부모가 보는 따뜻하고 밝은 톤. 각 25자 이내. 순서대로 초반→후반 감정선.
  예: `"처음엔 보드가 자꾸 미끄러졌어요"`, `"괜찮아, 넘어져도 다시!"`, `"어? 조금씩 되는데?"`, `"우와, 진짜 잘 탄다!"`, `"포기하지 않은 네가 최고야"`
- `note`는 사람이 보기 위한 메모(빌더는 무시함). 넣어두면 검수에 좋다.
