## 영상 길이·구성 (학생 영상과 다름)
- **60초** (JSON에 `"duration": 60` 필수)
- shots **17~19개** 권장(각 약 2.8초). 최소 14개까지 허용, 억지로 채우지 말 것.
- 동영상은 **최대 5개**(60초라 상향). `mediaStart`로 좋은 순간 지정.

## 스토리 구성 (저자 요청 순서)
아래 순서대로 shots를 배열하세요.

1. **첫 화면(hero)** — 강사가 가장 잘 나온 사진. 얼굴이 선명하고 밝고 표정이 좋은 컷.
2. **교육 과정** — 실내 브리핑/이론 설명 → 지상(모래) 자세 훈련 → 밸런스보드 → 스케이트보드 → 해변 실전 순서로 "가르치는 과정"이 보이게. (약 5~6컷)
3. **아이들을 잘 보살피는 모습** — 손 잡아주기, 무릎·골반 자세 교정, 헬멧 채워주기, 물에서 지켜보기, 넘어진 아이 일으켜 주기, 눈높이 맞춰 설명하기. **이 섹션이 영상의 중심**이니 가장 넉넉하게(약 6~7컷).
4. **직접 타는 모습 + 웃는 모습** — 강사 본인이 스킴보드/스케이트보드를 타는 시범 컷, 그리고 아이들과 함께 활짝 웃는 컷. (약 4~5컷)
5. **엔딩** — `cert` 슬롯에는 수료식 수여 장면이나 단체사진 중 강사가 잘 보이는 컷을 넣으세요(학생 영상의 '수료증' 자리에 해당).

## 말풍선 (가장 중요 — 학생 영상과 톤이 다름)
`messages`는 **7~8개**. 저자 요청: **"선생님들의 애정이 담긴 메시지"**.

→ 즉 **강사가 아이들에게 건네는 1인칭 말투**로 쓰세요. 아이를 칭찬·격려하는 학생 영상과 달리, 여기서는 **선생님의 마음**이 드러나야 합니다.

좋은 예시(그대로 쓰지 말고 실제 화면에 맞게 새로 쓸 것):
- "천천히, 넘어져도 괜찮아"
- "무섭지? 선생님 손 잡아"
- "한 번만 더 해보자, 할 수 있어"
- "발은 여기, 무릎은 살짝"
- "너희가 파도 타는 순간이 제일 좋아"
- "잘했어, 진짜 잘했어"
- "바다는 무서운 게 아니라 친구야"
- "내년에도 또 보자!"

규칙:
- 각 25자 이내, 한국어, 따뜻하고 담백한 말투(과장·유행어 금지)
- **화면에 보이는 장면과 맞아야 함** (자세 교정 컷에는 자세 관련 멘트, 웃는 컷에는 마음 표현 멘트)
- 감정선 순서: 처음 만남/설명 → 다독임 → 함께 연습 → 성취의 기쁨 → 마무리 인사

## JSON 추가·변경 필드
```json
{
  "slug": "teacher-gyuyoung",
  "duration": 60,
  "name": "규영",
  "suffix": "샘",
  "endName": "규영샘",
  "camp": "망남한뼘해변 스킴캠프",
  "date": "2026.09.05-06",
  "subtitle": "<강사에 맞는 한 줄 부제 (예: 아이들 손을 놓지 않은 이틀)>",
  "endBadge": "<예: 고맙습니다>",
  "endTitle": "<끝 카드 큰 글씨 (예: 또 만나요!)>",
  "hero": { "src": "...", "focus": "50% 32%" },
  "cert": { "src": "...", "focus": "45% 38%" },
  "shots": [ ... 17~19개 ... ],
  "messages": [ ... 7~8개 ... ]
}
```
- `name`/`suffix`를 나눠 쓰면 타이틀 카드에서 "규영"은 크게, "샘"은 작은 금색으로 표시됩니다. `endName`은 끝 카드에 쓸 전체 표기입니다.
- 민경샘은 `"name": "민경", "suffix": "샘", "endName": "민경샘"`.
