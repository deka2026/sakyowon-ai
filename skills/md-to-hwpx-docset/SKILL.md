# 마크다운 원본으로 한글 문서 세트 만들기

2026-09-25 망남마을협동조합 설립 서류 **7종**(정관 21쪽, 발기인대회 공고·회의록, 창립총회 공고·회의록, 2027 사업계획서·예산서) 제작으로 확립·검증.

## 왜 md를 원본으로 두는가

한글 문서를 직접 고치면 **고칠 때마다 서식 ID가 재매핑되고**(hwpx-powershell-edit 함정 8) 문서가 여러 개면 일관성이 깨진다. md를 원본으로 두면

- 문구 수정이 텍스트 한 줄 고치기로 끝나고, 7종을 한 번에 다시 뽑아도 서식이 흔들리지 않는다
- 숫자·상호참조를 **스크립트로 검증**할 수 있다 (사람 눈으로는 예산서 39개 합계를 못 맞춘다)
- 같은 원본에서 hwpx·docx·PDF를 모두 뽑을 수 있다

대신 **사용자가 한글에서 직접 고친 뒤에는 재생성하면 그 편집이 지워진다.** 아래 "사고" 절을 반드시 읽을 것.

## 절차

### 1. 서식 템플릿 고르고 채록

같은 폴더에서 서식이 마음에 드는 기존 hwpx를 하나 고른다. **사교원 12pt 규칙이 이미 적용된 산출물**을 고르면 후처리가 필요 없다.

```bash
python scripts/probe_styles.py "템플릿.hwpx"
```

출력에서 챙길 것:

| 항목 | 쓰임 |
|---|---|
| 본문폭 (`pagePr width − margin L − R`) | 표 폭 상한. 이걸 넘으면 오른쪽으로 삐져나간다 |
| 제목/절/본문/불릿 문단의 `pp`·`st`·`cp` | `styles` 에 넣을 값 |
| 첫 표의 `cell borderFill/parapr/charpr` | 머리행·본문행 서식 |

서식 ID는 문서마다 다르고 한글이 재저장하면 바뀐다. **전 세션 값을 재사용하지 말 것.**

### 2. docset.json 작성

`templates/docset.example.json` 을 복사해 고친다. 핵심은 `widths` — **md 표의 등장 순서대로** 열 폭을 적고, 각 줄의 합이 `body_width` 와 같아야 한다(다르면 생성이 중단된다).

### 3. md 작성

지원하는 문법과 매핑:

| md | 결과 |
|---|---|
| `# 제목` | 문서 제목 (secPr 운반 — 반드시 문서에 하나, 맨 앞) |
| `―― 부제 ――` | 부제 띠 |
| `## 제1장 총칙` | 장 제목 (제1장만 쪽 나눔) |
| `## 별표 1 · …` / `## 부칙` | 큰 제목 + 쪽 나눔 (`page_break_prefixes`/`page_break_exact`) |
| `## 1. 예산 총괄` | 큰 제목 (쪽 나눔 없음) |
| `### 가. 소제목` | 절 제목 |
| `> 안내문` | 작은 안내 문단 |
| `- 항목` | ● 불릿 |
| `1. 항목` | 들여쓴 호 |
| `　가. 항목` (전각공백) | 더 들여쓴 목 |
| `**굵게**` | 굵은 런 (문장 중간도 가능) |
| `\| 표 \|` | 표 (첫 행이 머리행) |

금지: 셀 안의 `|`(·로 대체), 본문의 `<` `>`.

### 4. 생성

```bash
python scripts/gen.py docset.json 정관
python scripts/gen.py docset.json --all
python scripts/gen.py docset.json 정관 --out-suffix _regress   # 산출물을 건드리지 않고 확인
```

`fix_tbl_ids` → `sanitize_package`(템플릿 Preview·제목 잔재 제거)까지 자동으로 돈다.

### 5. 검증 — 세 겹을 다 돌려야 완료

```bash
python scripts/verify.py "문서.hwpx" --body-width 46490 --articles 72
```

구조(표 폭·rowCnt·`treatAsChar=0`·미해결 서식 참조·마크다운 잔재·조문 누락)를 본다.

**숫자가 있는 문서는 별도 검증기를 그때그때 짠다.** 예산서라면 세목합·부문별 수지·분기 누적·문서 간 정합성을 전부 계산해 기대값과 대조한다. 2027년 예산서는 39항목을 검증했고, 그 과정에서 인건비 구조를 바꿔야 수지가 맞는다는 것을 발견했다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File `
  C:\Users\User\.claude\skills\hwpx-powershell-edit\scripts\pagecount_auto.ps1 `
  -HwpxPath "문서.hwpx" -Pdf
```

**XML 유효성만으로는 한글에서 열리는지 모른다.** 반드시 실제로 열어 쪽수와 PDF를 얻는다.

```bash
python scripts/contact_sheet.py "문서.pdf" cs.pdf            # 전 쪽 + 얇은 쪽 경고
python scripts/contact_sheet.py "문서.pdf" z.pdf --zoom 3,17 # 의심 쪽 확대
```

접촉시트를 Read 도구로 열어 **눈으로 본다.** 이번 세션에서 이 단계로만 잡힌 것이 5건이다.

## 조판에서 실제로 걸린 것 (2026-09-25)

| 증상 | 원인 | 처방 |
|---|---|---|
| 표 머리글이 "인수 출자좌/수", "서명 또는 날/인"으로 끊김 | 열이 좁음 | 열 폭 재배분(합은 유지) |
| 마지막 쪽에 2줄만 남고 1쪽 늘어남 | 표 뒤 빈 줄을 무조건 넣음 | 쪽나눔 없는 **번호 없는** 소제목 앞에만 |
| "경상수입 합/계" 두 줄로 접힘 | 첫 열 8000 | 10000으로 확대 |
| 쪽 경계에서 셀이 갈려 "월" 한 글자만 넘어감 | 두 줄짜리 셀이 경계에 걸림 | 산출근거 문구를 한 줄로 단축 |
| 표의 계층 들여쓰기가 안 보임 | `.strip()` 이 전각공백(U+3000)까지 지움 + **셀이 가운데 정렬** | `strip(' \t')` 로 바꾸고, 그래도 안 보이면 `·` 기호로 계층 표시 |

마지막 항목이 특히 함정이다. 전각공백을 살려도 **셀이 가운데 정렬이면 들여쓰기가 시각적으로 사라진다.** 계층은 기호로 표현할 것.

## 사고: 산출물에 회귀 테스트를 하지 말 것

변환기를 범용화한 뒤 "출력이 같은지" 확인하려고 이미 사용자에게 전달한 정관 hwpx를 다시 빌드했다. 그 사이 사용자가 한글에서 고쳤다면 그대로 덮어쓰는 행위였다(한글 백업 파일은 남지 않는다). 이번에는 사용자가 "수정한 거 없다"고 확인해 줘 피해가 없었지만, 운이었다.

**회귀 확인은 `--out-suffix _regress` 로 별도 파일에 뽑아 비교하고 지운다.** `gen.py` 에 그 옵션을 둔 이유다.

사용자가 한글에서 편집했을 가능성이 있으면, 재생성 전에 두 가지를 본다.

```bash
# 한글이 재저장한 파일인가 — 재저장본은 조판 캐시가 들어 있고 서식 ID가 재매핑돼 있다
python -c "import zipfile,re; s=zipfile.ZipFile('문서.hwpx').read('Contents/section0.xml').decode(); print('linesegarray:', s.count('<hp:linesegarray'))"
ls -la --time-style=full-iso 문서.hwpx      # 내 마지막 빌드 시각보다 뒤인가
```
