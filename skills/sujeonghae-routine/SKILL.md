# "수정해" 루틴 (hwpx 교정본 제작)

2026-08-28 사용자 확정. 발제문 2종(23건 / 12건+문단 4개 복원+표 7개)으로 검증. 도구는 스킬 `hwpx-powershell-edit`(인덱스 기반 경로)를 그대로 쓴다 — 이 스킬은 **무엇을 어떤 순서로 챙기는가**를 규정한다.

## 절차

### 0. 입력 확보
- 대상이 PDF·hwpx 쌍이면 **둘 다 읽고 교차검증**한다. 실증: hwpx에서 공론장 질문 4개 문단이 유실된 것을 PDF 대조로 발견 → PDF 기준 복원.
- hwpx가 한글에서 열려 있으면(잠금) **절대 프로세스를 죽이지 말고** 사본을 복사해 작업. 디스크 판 기준임을 사용자에게 고지.

### 1. 오류 수집 (두 종류를 구분해 목록화)
- **오탈자·표기**: 띄어쓰기(여러 가지, 부서 간), 문장부호(콜론 앞 공백, 쉼표 누락, 마침표 유무), 기호 뒤 공백(❹광주시, 25%·), 이중 공백, 조사 오류()가/)이), 범위 표기 통일(5~6개 vs 5-6개), 목차↔본문 제목 일치.
- **논리 오류** (이 문서군에서 실제 나온 유형):
  - 산술: "2014년 발의 이후 13년 만"(→12년), 표 합계 vs 개요 수치
  - 상호참조: 본문이 표와 모순("네 자산이 ❹과의 네 팀" ↔ 표에는 ❺과 소관 자산), 다른 절 인용 오류("5-3의 네 개 조항(…)"의 괄호 내용이 실제 조항이 아님)
  - 개수: 조직도 6개 ↔ 본문 "5개", 모델 5개 ↔ "6개 시군"
  - 기준 불일치: "민간 과반" ↔ "민간 2/3"(상세 설계 쪽으로 통일), 같은 기금의 수단이 절마다 다름(출자/융자)
  - 업무 중복: 같은 사업이 두 팀 핵심사업에 복제(담당표 기준으로 한쪽 제거)
- **수치가 어긋나는데 어느 쪽이 맞는지 판단 불가**면 고치지 말고 "저자 확인 필요"로 보고서에 분리 기재.

### 2. 빨간색 교정 적용 (hwpx-powershell-edit 경로 A)
1. `hwpx_dump.ps1` → 인덱스 확보 (**대괄호 안 숫자** 사용, 줄번호 아님)
2. header.xml `itemCnt` 확인 → `add_red_charpr.ps1 -Offset <itemCnt>` (red(N)=N+itemCnt)
3. REPLIN 일괄 → 재덤프 → INS(복원 문단은 red charPrIDRef, 기존 동종 문단의 paraPr 재사용 — 자동번호 목록이면 같은 paraPr로 삽입해야 번호가 이어짐)

### 3. 표 폭 교정 (텍스트 교정과 별도, 빨간색 불필요)
- 본문폭 = `hp:pagePr@width − hp:margin@left − right` (secPr에서 매번 계산. 사교원 발제문 템플릿 = 59528−6519×2 = **46490**)
- 초과 표: `hp:sz@width`를 본문폭으로 줄이고, **각 hp:tr의 마지막 hp:tc cellSz@width에서 초과분 차감** (행별 합 유지). XmlDocument(DOM)로 처리, UTF-8 no BOM 저장.
- 검증: 전 표 재스캔(초과 0, 음수 셀 0).

### 4. 출력·검증
- `hwpx_repack_multi.ps1`로 **새 파일** `<원본명>_교정_v1.0.hwpx` (원본·PDF는 불변)
- 재덤프 양방향 검증: 새 문자열 존재 + 옛 문자열 0회. 빨간색 런 분할로 긴 문자열이 끊기므로 조각 단위로 카운트. "6개…"⊂"5~6개…" 같은 부분 문자열 오탐 주의.
- `SendUserFile`로 전달.

### 5. 보고 (필수 구성)
① 논리 오류(내용이 바뀐 것) — 근거와 함께 개별 설명 ② 단순 오탈자 — 묶어서 ③ 표 폭 교정 내역 ④ **수정하지 않은 것**(저자 확정 필요 수치, 의도로 판단해 보존한 것) ⑤ "한글에서 검토·수락 후 빨간색 해제하면 최종본" 안내.

## 함정
- 검토 없이 이 교정본을 최종본으로 삼지 말 것 — 빨간색은 사람 검토용.
- 판단이 서지 않는 고유명사("다해-드림"/"해드림"), 문서 전체에서 일관된 팀명은 건드리지 않는다.
- 이전 판에서 고친 오류가 새 판에 재유입되는 경우가 있다(5-6개 등) — 최신 메모리·핸드오버의 교정 이력을 먼저 확인.
