# 핸드오버 — 망남 마을민박 사업계획·참가신청서 (2026-08-23)

## 세션 개요

망남마을 마을민박(농어촌민박) 사업 검토부터 사업계획서·주민 참가신청서 한글 파일 산출까지 진행한 세션.

## 진행 내용

### 1. 마을민박(농어촌민박) 신청 절차·요건 조사
- 법률상 정식 명칭은 **농어촌민박사업**(농어촌정비법 제86조). 신고 요건: 농어촌지역 주민 + 관할 시군 **6개월 이상 거주** + **본인 소유·실거주** 단독/다가구주택 + **연면적 230㎡ 미만**(부속건물 합산). 3년 이상 거주자는 임차 주택도 가능(2년 이상 운영 조건).
- 절차: 완도군청에 신고(정부24 온라인 가능) → **10일 이내** 수리 통지(무통지 시 자동 수리) → 신고확인증 발급.
- 시설 기준: 객실별 소화기·화재감지기, 난방·취사 객실 일산화탄소 경보기, 지하수는 2년 이내 수질검사성적서. 운영자 매년 안전교육.
- 농어촌정비법 개정 조항이 2026-01-02 시행 — 실제 신고 전 완도군청 최신 기준 확인 필요.

### 2. 협동조합 운영 방안 (법인은 농어촌민박 신고 불가)
- **A안**: 도농교류법 제5조 **농어촌체험·휴양마을 지정**(마을협의회·어촌계 명의, 마을 단위 숙박·음식 합법) + 조합 위탁운영 — 중기 목표.
- **B안**: 조합원 **개별 신고 + 조합 통합운영**(예약·마케팅·청소·정산 대행) — 즉시 가능, 채택.
- **C안**: 조합 명의 숙박업 등록(용도변경 필요, 비용 큼) / 빈집재생민박업(실증특례 단계) — 보류.

### 3. B안 사업계획 수립
- 요금: 1일 6만 / 1주 25만 / 1개월 50만 원.
- **배분 구조(사용자 지시로 변경)**: 매출에서 **관리운영비 15% 우선 공제 → 잔여 85%를 가구:조합 = 5:5(각 42.5%)**.
- 예약율 20/30/40% 시나리오 × 상품 3유형별 가구당 수지, 필요 가구 수 산정(기준: 관리운영비로 조합 운영 실비 확보 — 시범 월 50만/안정 월 100만).
  - 단기여행형: 5~10가구(시범선) / 일주일살기형 8~16 / 한달살기형 17~34(단독 비현실).
- **권장안**: 7가구(단기 6 + 한달살기 1), 예약율 30% 목표 → 마을 월 매출 약 339만, 가구당 순수입 약 23만(회수 약 13개월), 조합 총수입 약 195만(관리운영비 51만 + 배분수익 144만, 배분수익은 적립·마을기금).
- 가구당 초기 시설투자 약 300만 원(안전설비 30 + 정비 150 + 비품 105 + 수질검사 15) 가정.
- 리스크: 5:5 배분으로 가구 유인 약화 → 시설투자비 보조·한시적 배분율 우대 검토를 대응책으로 명시.

### 4. 주민 참가신청서 제작
- 정부24 정식 신고서 항목을 모두 미리 받는 구성(인적사항·주택정보·시설현황·운영희망·동의/서명).
- **주민등록번호는 수집하지 않음**(정부24에서 본인 직접 입력 안내) — 조합의 개인정보 관리 부담 회피.
